# Awesome Merged Skills v2

Additional 15 skills merged from awesome-claude-skills (ComposioHQ).

## 📊 Productivity Tools (3)

### changelog-generator
Automatically creates user-facing changelogs from git commits.
- Categorizes changes (features, fixes, breaking)
- Translates technical commits to user-friendly language
- Filters noise (refactoring, tests)

### meeting-insights-analyzer
Analyzes meeting transcripts for communication patterns.
- Identifies conflict avoidance
- Speaking ratio analysis
- Leadership style feedback
- Trend tracking over time

### slack-gif-creator
Creates animated GIFs optimized for Slack.
- Optimized for Slack size limits
- High quality compression
- Text overlay support
