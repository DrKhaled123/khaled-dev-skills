## 🛠️ Project Templates

### MERN Starter Template
```javascript
// server.js (Express)
const express = require('express');
const mongoose = require('mongoose');
const cors = require('cors');

const app = express();
app.use(cors());
app.use(express.json());

// Routes
app.use('/api/items', require('./routes/items'));

// MongoDB connection
mongoose.connect(process.env.MONGODB_URI)
  .then(() => console.log('MongoDB connected'))
  .catch(err => console.log(err));

const PORT = process.env.PORT || 5000;
app.listen(PORT, () => console.log(`Server running on port ${PORT}`));
```

```javascript
// App.js (React)
import React, { useState, useEffect } from 'react';
import axios from 'axios';

function App() {
  const [items, setItems] = useState([]);

  useEffect(() => {
    axios.get('/api/items')
      .then(res => setItems(res.data));
  }, []);

  return (
    <div className="App">
      <h1>My Full Stack App</h1>
      {items.map(item => (
        <div key={item._id}>{item.name}</div>
      ))}
    </div>
  );
}

export default App;
```

### Flask Starter Template
```python
# app.py
from flask import Flask, jsonify, request
from flask_sqlalchemy import SQLAlchemy
from flask_cors import CORS

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///app.db'
CORS(app)
db = SQLAlchemy(app)

class Item(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)

@app.route('/api/items', methods=['GET', 'POST'])
def items():
    if request.method == 'POST':
        item = Item(name=request.json['name'])
        db.session.add(item)
        db.session.commit()
        return jsonify({'id': item.id, 'name': item.name})
    
    items = Item.query.all()
    return jsonify([{'id': i.id, 'name': i.name} for i in items])

if __name__ == '__main__':
    app.run(debug=True)
```

## 💡 Best Practices

1. **Project Structure**: Organize by feature, not layer
2. **API Design**: RESTful conventions
3. **State Management**: Choose wisely (Redux, Vuex, Context)
4. **Authentication**: JWT or Session-based
5. **Database**: Index frequently queried fields
6. **Error Handling**: Consistent error responses
7. **Testing**: Unit + Integration + E2E
8. **Security**: Validate inputs, sanitize outputs
9. **Performance**: Lazy loading, pagination, caching
10. **Deployment**: Docker, CI/CD, monitoring
